# KLEOS

A prototype exchange for public attention. Traders buy and sell a persistent **VIP Index Share** priced by a per-VIP bonding curve; every listed VIP has a (fictional, for this demo) executed NIL license and earns half of all trading fees on their own index.

Built from the condensed spec in [`SPEC.md`](./SPEC.md).

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

Production: `npm run build && npm start`. Requires Node 18.18+.

## What's inside

| Route | What it does |
|---|---|
| `/` | Discovery — VIPs grouped by category (music, film/TV, sports, creators, reality TV) |
| `/vip/[slug]` | Market page — live curve-driven chart, reserve/volume stats, Interest Index with named sources, verified updates, buy/sell panel with price-impact preview |
| `/portfolio` | Balance, holdings (incl. honest exit estimate after curve impact + fees), watchlist, trade history |
| `/vip-dashboard` | NIL-partner economics demo — per-VIP fee earnings, license status, insider-trading rules |
| `/methodology` | Published curve formula, fee schedule, index sources per category, guardrails, regulatory flags |
| `/api/trade` `/api/vips` `/api/watchlist` | JSON API used by the trade panel and smoke tests |

## The curve (documented formula)

```
price(s)          = basePrice + slope × s
buyCost(s, n)     = ∫ₛ^(s+n) price = basePrice·n + slope·(s·n + n²/2)
sellProceeds(s,n) = ∫₍ₛ₋ₙ₎^s price = basePrice·n + slope·(s·n − n²/2)
```

Trades execute against a per-VIP reserve that always equals `∫₀^s price` — fully backed, always liquid, no order book. A flat 2% fee (never touching the reserve) is split 50/50 between platform and VIP. Implementation: [`lib/curve.ts`](./lib/curve.ts). Price impact (blended vs. spot) is shown before every confirmation.

## Architecture

- **Next.js 15 (App Router) + TypeScript + Tailwind v4** — server components read the store directly; the trade panel is a client component that quotes locally with the same curve math and executes via `POST /api/trade`, then refreshes.
- **In-memory store** ([`lib/store.ts`](./lib/store.ts)) on `globalThis` — survives HMR, resets on server restart by design. Single demo trader with $10,000 virtual USD.
- **Seed data** ([`lib/seed.ts`](./lib/seed.ts)) — 8 fictional VIPs; price history is generated by simulating trades along each VIP's actual curve with a deterministic PRNG, so history, reserve, and price are mutually consistent.

## Guardrails in this build

Opt-in NIL licensing surfaced on every market · 18+ age gate (geofencing noted for production) · flat-fee split with the VIP · published index methodology with named public sources, no personal-life signals · insider-trading rules in VIP-facing copy · early-buyer/late-buyer curve asymmetry disclosed on cards, market pages, and in the trade flow · virtual USD only, with real-money regulatory flags in `/methodology` and `SPEC.md`.

**All VIPs are fictional.** No real person may be listed without an executed NIL license — that rule is the product.
